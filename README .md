# 四级抽词器（CET4 Word Quizzer）

一个**单文件、零依赖、可离线使用**的网页背单词小工具：导入词表文档后随机抽 45 个单词，逐个展示英文，按空格显示中英文对照。

内置 1232 个四级高频核心词，不导入任何文件也能直接用。

## 功能

- 随机抽词：每轮抽取数量可自定义（默认 45 个，设置会记住；剩余不足时全抽）
- 翻面测试：只看英文，按空格 / 回车 / 点击卡片显示答案，再按一次进入下一个
- 记住即出池：过完一个单词默认记为"已掌握"，之后的轮次不会再抽到
- 没学会标记：答案界面可标记"没学会"，该词留在池子里，下次还会被抽到（每次重新判定）
- 学习记录持久化：已掌握名单存在浏览器 localStorage 中，关闭页面再打开仍然有效
- 重置记录：一键清空学习记录
- 自定义词表：支持导入自己的词表文档

## 使用

### 本地使用

下载 `index.html`，用浏览器（Chrome / Edge / Safari 等）打开即可，无需安装任何东西，无需联网。

### 部署到 GitHub Pages

1. Fork 或新建仓库，把 `index.html` 传到仓库根目录
2. 仓库 Settings → Pages → Source 选择 `main` 分支根目录
3. 等待一两分钟，访问 `https://你的用户名.github.io/仓库名/` 即可在线使用（手机也可以）

## 导入词表格式

支持三种格式，**一行一个词条**：

**1. TSV（Tab 分隔，推荐）**

```
abandon	v. 放弃；抛弃
ability	n. 能力；才能
```

**2. Markdown 列表**

```
- **abandon**  v. 放弃；抛弃
```

**3. 纯文本（空格分隔）**

```
abandon v. 放弃；抛弃
```

注意：

- 文件编码请使用 UTF-8，否则中文可能乱码
- 不支持 .xlsx / .docx，请先在 Excel 中另存为"制表符分隔的文本"
- 不需要表头，空行会被自动忽略
